# Bip 6 Cinema

Five 390×450 Amazfit Bip 6 watchfaces with live time, weekday, date, steps, heart rate, and battery. Each movie folder contains a built .zab, an editable Dialcraft project, a Zeus project, the original ImageGen numeral sheet, and previews.

## Clock artwork

The normal clock uses all ten digits and the colon from one ImageGen sheet per movie. Slicing removes the black background. One proportional scale fits the whole set into the clock area, with padding for the fixed-width Zepp OS digit cells. The original sheet stays in each movie’s folder.

The preview galleries include 10:09 and 17:26. The reference comparison uses the original 16:25 sample and shows a visual overlay and difference image.

All five projects built with Zeus and reopened in Dialcraft for preview. Physical watch testing is pending.
